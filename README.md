# UTravel Explorer

A Flutter-based Travel Destination Explorer application developed for the CODIORA House Mobile Application Development Internship – Week 2 Task.

## 📱 Features

- Splash Screen
- Home Screen
- Destination Listing
- Destination Search
- Category Filtering
- Destination Details Screen
- Smooth Navigation
- Responsive UI

## 🛠️ Tech Stack

- Flutter
- Dart
- Material Design

